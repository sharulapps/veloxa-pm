1 Firebase Config
Dapatkan dari Firebase Console → Project Settings → Your Apps → SDK setup
📋 Cara dapat Firebase config:
  1. Pergi console.firebase.google.com → Add project → nama: veloxa-mnsb
  2. Dalam project → klik ikon </> (Web) → Register → nama: VELOXA Web
  3. Copy semua values dari firebaseConfig → paste kat bawah
  4. Pergi Authentication → Get started → Enable Email/Password + Google
  5. Pergi Firestore Database → Create database → Production mode → region: asia-southeast1

2 Resend Email Config OPTIONAL
Untuk welcome email & reset password via Resend + Cloudflare Worker. Boleh skip dulu, setup kemudian.
📋 Cara setup Resend + Cloudflare Worker:
  1. Daftar di resend.com → Dashboard → API Keys → Create API Key → copy re_xxxx
  2. Verify domain ko kat Resend (or guna onboarding@resend.dev untuk test)
  3. Pergi dash.cloudflare.com → Workers & Pages → Create Worker
  4. Namekan worker: veloxa-email-worker → Deploy
  5. Edit worker → paste semua code dari worker.js dalam ZIP → Save & Deploy
  6. Worker Settings → Variables → Add:
    RESEND_API_KEY = re_xxxxxxxxxxxx (set as Secret)
    FROM_DOMAIN = domain email ko (contoh: mnsb.com)
  7. Copy URL worker: https://veloxa-email-worker.yourname.workers.dev → paste kat bawah
  8. Worker Settings → HTTP → CORS → tambah domain Cloudflare Pages ko dalam ALLOWED_ORIGINS dalam worker.js

3 App Config
Maklumat syarikat dan admin pertama
⚠️ Selepas download & upload ke Cloudflare:
  1. Firebase Console → Authentication → Users → Add user → masuk email & password admin
  2. Copy User UID yang dijana
  3. Firestore → Start collection → ID: users → Document ID: (UID tadi)
  4. Add fields: name: nama ko, email: email ko, role: admin, workspaceId: default, status: active
  5. Buat collection workspaces → Doc ID: default → field name: MNSB
  6. Firebase → Authentication → Settings → Authorized domains → tambah domain Cloudflare ko
